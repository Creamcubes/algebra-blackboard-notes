# Lecture project instructions

Read `LECTURE_REQUIREMENTS.md` in this directory before working on textbook learning, lecture content, the website, or print materials. It contains general requirements for all lectures. New user instructions take precedence.

The current content entry point is `content/lecture-source.json`. Read the latest content before editing. Do not overwrite it with historical scripts or old website content.

Determine each lecture's starting point from the user's actual progress, existing lecture materials, and the textbook. Do not hard-code a particular lecture's stopping point in long-term instructions. Preserve materials from other lectures.
